## Getting the source

The installer ships two prebuilt images: the FPGA bitstream and the ESP32 firmware. Their
complete corresponding source is this release (`shiny-relay-src-<version>.tar.gz`),
published at the same place as the installer, with the build scripts and the exact tool
versions in `docs/BUILDING.md`. The installer's `images/manifest.json` names the commit and
sha256 of each image.
